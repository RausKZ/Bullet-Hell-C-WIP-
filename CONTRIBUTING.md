# 🚀 Contributing to Our Project
First off, thank you for considering contributing! It's people like you that make open source such a great community.
## 📌 The process
We want to review ideas and discuss implementation details before you spend your valuable time writing code.
1. Find or Open an Issue: Check the issues tab to see if your proposed feature or bug fix is already being discussed. If not, open a new issue detailing what you want to change.

2. Wait for Acceptance, a maintainer will review your issue.

3. Once a maintainer approves the issue, you are officially clear to start!

## 🚀 Creating Your Pull Request
Before making a pull request, make sure your code compiles and everything runs correctly, then open a Pull Request against our main branch.

Link the Issue (Required): You must link your PR to the original accepted issue.

A maintainer will review your code. Be prepared to address feedback or make minor requested changes before it gets merged.
